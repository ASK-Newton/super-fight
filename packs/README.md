## 导入步骤
1. 打开 `super-fight.html`。
2. 左侧导航进入「内容库」。
3. 点「导入」，选择本目录下的 `.json` 文件（可一次选多个）。
4. 导入后引擎自动归类；到「开始训练」即可选用。
