# 超级对决 SUPER FIGHT · V0.5.0

一款面向**辩论 / 演讲训练**的单文件对局控制台。双方各自抽取「角色 + 能力 + 缺陷」，共享同一「环境」与「胜利条件」，在训练中植入海克斯与环境事件，由教练把控环节与计时。所有数据存于浏览器本地（IndexedDB），无需联网、无需服务器。

## 一、怎么用（三种拿到方式）

- **A. 单文件（最省事）**：直接双击打开 `super-fight.html`，或拖进浏览器。一个 HTML 文件搞定全部功能，可拷到 U 盘、发给队友。
- **B. 静态站点**：把整个 `发布/v0.5.0/` 文件夹托管到任意静态空间（GitHub Pages / 对象存储 / CloudStudio 沙箱），访问 `index.html` 即可，适合给全队一个固定链接。
- **C. 开源仓库**：克隆仓库后使用，便于二次开发与提交改进（见文末「参与共建」）。

首次打开后，在「内容库」里点「导入」，把 `packs/` 下的内容包（`.json`）逐个导入即可开始训练。

---

## 二、V0.5.0 新增能力

- **卡牌详情点按展开**：在对局 / 揭晓 / 投影任意界面，点角色、能力、缺陷、海克斯、环境、环境事件、胜利条件，即可弹出完整描述（不熟悉牌池的辩手也能看懂题面）。
- **双计时器**：自由辩等需要双方分开计时的环节，可在环节配置里开启双计时。支持任意加 / 减时间、减到 0 封顶、单方重置与单方增减，撤销时正确回算剩余时间。
- **环节配置（Timeline Builder）**：教练可自由增减陈词、自由辩、质询、环境事件、海克斯选取等环节数量，并拖拽调整顺序；无判票环节时末环节显示「结束对局」。

以上三项均通过真实浏览器（Edge）复现与回归测试，引擎自带断言套件 101 项全绿。
